# Python Slides

Interactive Python lessons in English and Bahasa Indonesia.

**Live site:** https://vetame21.github.io/python-slides/

## Sources and credits
The slides are written in my own words from these sources, and each slide links
the pages it used:

- [Python documentation](https://docs.python.org/3.13/)
- [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/)
- [W3Schools Python tutorial](https://www.w3schools.com/python/)
- [GeeksforGeeks Python tutorials](https://www.geeksforgeeks.org/python/)

This project is not affiliated with or endorsed by any of them. Anything not from
a source is tagged `[ADDED]`.
