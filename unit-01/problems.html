Unit 1 problems

Open a problem to read it. Inputs are typed one per line, in the order shown. Write each solution as a script and run it in Python.

1Tip CalculatorEasy
Read the bill, then the tip percent. Print the total with exactly 2 decimal
places.

Example 1:
  Input:  50, 15
  Output: Total: 57.50

Example 2:
  Input:  80, 0
  Output: Total: 80.00

Constraints:
  0 <= bill, 0 <= tip percent. Both may have decimals.

Hint: slide 8 shows how to control decimal places.
2Clock FormatMedium
Read a number of seconds. Print it as H:MM:SS. Minutes and seconds always use
2 digits, but hours use as many digits as they need.

Example 1:
  Input:  3725
  Output: 1:02:05

Example 2:
  Input:  59
  Output: 0:00:59

Example 3:
  Input:  360000
  Output: 100:00:00

Constraints:
  0 <= seconds. The input is a whole number.

Hint: f"{5:02d}" prints 05. The 0 pads with zeros and the 2 is the width.
3Rupiah ChangeMedium
Read an amount in rupiah. Pay as much of it as you can with the fewest notes,
using 10000, 5000, 2000 and 1000 notes. Print how many of each note you use
and how much is left.

Example 1:
  Input:  18200
  Output: 10000: 1, 5000: 1, 2000: 1, 1000: 1, Left: 200

Example 2:
  Input:  4000
  Output: 10000: 0, 5000: 0, 2000: 2, 1000: 0, Left: 0

Constraints:
  0 <= amount. The input is a whole number.

Hint: start with the biggest note. What remains after you use it?
4Reverse DigitsHard
Read a 3-digit number. Print its digits in reverse order, as a number, so
zeros at the front disappear.

Example 1:
  Input:  123
  Output: 321

Example 2:
  Input:  120
  Output: 21

Example 3:
  Input:  100
  Output: 1

Constraints:
  100 <= number <= 999
  Use math only. No slicing or indexing, such as text[::-1].
5Boxes NeededHard
Read the number of items, then how many items fit in one box. Print the
fewest boxes needed to hold every item. A box may be partly full.

Example 1:
  Input:  10, 3
  Output: 4

Example 2:
  Input:  9, 3
  Output: 3

Example 3:
  Input:  0, 3
  Output: 0

Constraints:
  0 <= items <= 10 ** 18
  1 <= items per box
  No if, no float, no / and no imports.
